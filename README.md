# Task 4: Classification with Logistic Regression

## Objective
Build a binary classification model using Logistic Regression.

## Dataset
Breast Cancer Wisconsin Dataset.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Steps Performed
1. Loaded the dataset.
2. Removed unnecessary columns.
3. Converted diagnosis labels:
   - B = 0 (Benign)
   - M = 1 (Malignant)
4. Separated features and target variable.
5. Split the dataset into training and testing sets.
6. Standardized the features using StandardScaler.
7. Trained a Logistic Regression model.
8. Generated predictions and probabilities.
9. Evaluated the model using:
   - Accuracy
   - Confusion Matrix
   - Precision
   - Recall
   - ROC-AUC
10. Plotted the ROC curve.
11. Compared different classification thresholds.
12. Visualized the Sigmoid function.

## Model
Logistic Regression

## Evaluation Metrics
The model was evaluated using accuracy, precision, recall, confusion matrix and ROC-AUC.

## Conclusion
Logistic Regression was successfully implemented as a binary classification model. The model performance was evaluated using multiple classification metrics and different probability thresholds.
